# Getting Started

## Installation

Install the package via npm:

```bash
npm install @ar-coder/otp-pro-input
```

## Basic Concepts

OTP Pro Input consists of a core engine and framework-specific adapters. All adapters share the same logic for:

- Input validation (numeric only)
- Paste distribution
- Mobile OTP autofill
- Focus management

Choose the adapter that fits your stack!
